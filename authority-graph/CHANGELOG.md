# Changelog

All notable changes to the Authority Graph Specification are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/). The specification uses [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-04-01

### Added

- Initial draft specification
- Authority Unit schema with six-property encoding
- Expression model with tree-structured predicates (comparison and compound types)
- Four edge types: delegation, composition, precedence, scope overlap (diagnostic)
- Authority Domain schema with domain contracts and export policies
- Composition Contract schema with per-interaction-class rules and conflict resolution
- Constitutional Hierarchy with three-tier evaluation precedence
- Monotonic Reduction Protocol with trigger conditions, reduction rules, and governance findings
- Graph Analysis Functions: scope overlap detection, gap detection, delegation depth analysis, compositional reachability check
- Arbitration Interface: request/response schemas with mandatory legibility record
- Graph Validity Rules (eight rules for deployment readiness)
- Appendix A: Type Definitions (all referenced types formally defined)
- Appendix B: Minimal Complete Example (three-agent document processing system)
- Appendix C: Implementation Notes (identity integration, naming conventions, where-to-start methodology, algorithmic notes)
